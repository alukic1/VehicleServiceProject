# VehicleServiceProject
Vehicle service management system (clients, appointments, parts, invoices),
built as a university project at the University of Banja Luka, Faculty of Electrical Engineering.

See the full project description: [Project_description.pdf](Project_description.pdf)

## Configuration

Real config files are not included because they contain credentials.
Copy `config.properties.example` to `config.properties` and fill in your own
values (email and app password, keystore path and password, data file paths).

## Not included

`config.properties`, `*.jks`, `clients.xml`, `appointments.out`, `invoices/`
